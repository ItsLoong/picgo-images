# Cloudflare Worker

Reads the public images-index.json generated by GitHub Actions. No GitHub token is needed. Image routes return 302 redirects to raw.githubusercontent.com; Worker does not proxy image bytes.

## Deploy
```bash
npm install
npm test
npm run dev
npm run deploy
```

## Routes
- GET /health
- GET /api/catalog
- GET /wallpaper?device=desktop&resolution=4k&scene=nature (302)
- GET /avatar?scene=anime&min_size=512 (302)
- GET /api/wallpaper?... and /api/avatar?... (JSON)
- GET /api/random?type=wallpaper&count=5 (JSON)

Filters: device=desktop|mobile, resolution=1080p|2k|4k|8k (minimum long/short side), orientation=landscape|portrait|square, scene, tag, size=512x512 (exact), min_size=512 (both dimensions), count=1..20.
